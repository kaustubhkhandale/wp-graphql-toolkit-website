# WP GraphQL Toolkit Website

## Development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## GitHub Pages

The site is statically exported and deployed by `.github/workflows/deploy-pages.yml`.

1. Push the repository to GitHub.
2. Open **Settings > Pages** in the GitHub repository.
3. Set **Source** to **GitHub Actions**.
4. Push to `main` or manually run the workflow from the **Actions** tab.

For the root URL `https://kaustubhkhandale.github.io/`, the GitHub repository must be named `kaustubhkhandale.github.io`.

With the current repository name, the site URL is:

`https://kaustubhkhandale.github.io/wp-graphql-toolkit-website/`
