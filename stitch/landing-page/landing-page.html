Developer Questions

Does this support custom ACF fields? expand_more
Absolutely. If the fields are exposed to WPGraphQL (via the ACF GraphQL extension), Toolkit will automatically detect them, parse their types, and allow you to build queries for them visually.
Is the code exported production-ready? expand_more
Yes. We use standard GraphQL syntax and can export directly to .graphql files or string templates for use in Apollo, Relay, or native fetch requests.
Does it work with multisite? expand_more
Yes, WP GraphQL Toolkit is fully compatible with WordPress Multisite installations. You can manage queries across your entire network.
